# عصفورة الويب 🐦 — البنية التحتية

> منصة تجمع المصادر التعليمية المجانية والفرص المهنية والمسارات الوظيفية الموثوقة للمستخدمين في مصر — في مكان واحد.

**الحالة الحالية:** البنية التحتية مكتملة 100% — بدون أي محتوى وهمي، جاهزة لاستقبال البيانات.

---

## 1. نظرة سريعة

- **التقنيات:** HTML5 + CSS3 + JavaScript فقط (بدون React/Vue/Angular)
- **التصميم:** عصري، متجاوب، يدعم الوضع الفاتح/الداكن
- **اللغة:** عربية RTL بالكامل — خط IBM Plex Sans Arabic + Tajawal
- **الوصول:** دلالات HTML صحيحة، Skip Link، ARIA، Focus Visible
- **الأداء:** لا اعتماد على خدمات خارجية مدفوعة — كل شيء محلي

## 3. الصفحات والمكونات المشتركة

### الصفحات المُنشأة (5)

1. **`index.html`** — Landing: شارة حالة، Hero بعنوان ووصف وأزرار CTA، معاينة توضيحية للبطاقات، قسم الأقسام الرئيسية (3 بطاقات)، قسم "كيف أضيف المحتوى" (3 خطوات)، Empty State يؤكد عدم وجود محتوى وهمي، CTA نهائي.
2. **`pages/courses.html`** — مصادر الكورسات: Breadcrumb، Page Header، شريط فلاتر (الكل/برمجة/تصميم/أعمال/إنجليزي/شهادة)، Empty State رئيسي + معاينة بطاقة مصدر + شبكة مواضع توضيحية.
3. **`pages/scholarships.html`** — المنح والدورات: فلاتر (دراسية/تدريبية/دورات/ممولة/عن بُعد/حضوري)، تبويبات توضيحية، معاينة بطاقة منحة (نوع التمويل + الموعد + الوصف)، شبكة مواضع.
4. **`pages/career-paths.html`** — المسارات: فلاتر مجالات + زر "معاينة صفحة مسار" يؤدي للنموذج، شبكة مواضع بطاقات المسارات.
5. **`pages/career-path.html`** — نموذج مسار واحد: Header بالعنوان والوصف، أزرار حفظ/مشاركة، عمود رئيسي (نظرة عامة + Roadmap بثلاث مراحل توضيحية)، شريط جانبي (معلومات المسار + مصادر مقترحة + تعليمات النسخ).

### المكونات المشتركة في كل الصفحات

- **Navbar** متجاوب: شعار + 4 روابط + حقل بحث في المنتصف + زر الثيم + زر الهامبرجر (يظهر <860px). على الجوال تتحول الروابط والبحث إلى قائمة منسدلة كاملة.
- **بحث** في المنتصف + نافذة متراكبة (Overlay) تفتح عند التركيز أو الضغط، تدعم `Esc` للإغلاق واختصار `/` و `Ctrl+K`، وتعرض Empty State ذكي (حالة فارغة / لا نتائج).
- **زر الوضع الداكن/الفاتح** مع حفظ في `localStorage` ومزامنة مع تفضيل النظام، وتغيير `theme-color`.
- **Footer** بثلاثة أعمدة (البراند + الأقسام + حالة القسم) وحقوق.
- **Empty States** موحدة في كل قسم توضح أن المحتوى بانتظار الإرسال.
- **Toast** لإشعارات واجهية ("التصفية واجهة فقط حاليًا").

## 4. الوظائف: ما يعمل وما هو واجهة فقط

| الميزة | الحالة | التفاصيل |
|--------|--------|----------|
| التنقل بين الصفحات | ✅ يعمل | روابط حقيقية + تمييز الرابط النشط تلقائيًا + Breadcrumb |
| الوضع الداكن/الفاتح | ✅ يعمل | حفظ في localStorage، انتقال سلس، لا وميض، مزامنة مع النظام |
| قائمة الجوال | ✅ تعمل | فتح/إغلاق، إغلاق بـ Esc أو عند اختيار رابط أو تغيير الحجم |
| البحث — الشكل والتفاعل | ✅ واجهة كاملة | حقل مركزي + Overlay + اختصارات لوحة المفاتيح + عرض Empty State حسب الاستعلام |
| البحث — النتائج الفعلية | ⏳ واجهة فقط | لا قاعدة بيانات — ستُربط عند إرسالك للمحتوى دون إعادة بناء |
| الفلاتر والتصنيفات | ⏳ واجهة فقط | أزرار تفاعلية تُظهر Toast وتغيّر الحالة البصرية، بانتظار البيانات |
| خارطة الطريق | ✅ هيكل مكتمل | 3 مراحل توضيحية قابلة للتوسع لأي عدد، مع مواضع روابط المصادر |
| البطاقات والمحتوى | ⏳ Empty States | لا بيانات وهمية — مواضع توضيحية تختفي تلقائيًا عند ظهور المحتوى |

## 5. كيفية التشغيل

لا يحتاج تثبيت أو بناء — افتح الملفات مباشرة:

```bash
# من مجلد المشروع
# الطريقة 1: افتح مباشرة
open index.html

# الطريقة 2: خادم محلي بسيط (اختياري)
python3 -m http.server 8000
# ثم افتح http://localhost:8000
# أو
npx serve .
```

> ملاحظة: بسبب استخدام مسارات نسبية (`../css/...`)، يُفضل تشغيله عبر خادم محلي لضمان عمل كل الروابط، لكن الفتح المباشر يعمل أيضًا في أغلب المتصفحات.

## 6. كيفية إضافة المحتوى (الخطوة التالية)

### أ. مصادر الكورسات
أرسل جدولًا أو قائمة بكل مصدر: `الاسم | الوصف المختصر | التصنيف | نوع الشهادة | الرابط | أيقونة (اختياري)`. سيتم تحويل كل صف إلى بطاقة في `courses.html` مع تفعيل الفلاتر والبحث.

### ب. المنح والدورات
لكل فرصة: `العنوان | الجهة | نوع التمويل | الموعد النهائي | المكان (حضوري/عن بُعد) | الوصف | الرابط الرسمي`. ستُعرض في `scholarships.html` ببطاقة تحتوي كل هذه الحقول.

### ج. المسارات الوظيفية
1. حدد أسماء المسارات (مثل: تطوير الويب، علوم البيانات ...).
2. لكل مسار أرسل: `العنوان | الوصف | المهارات | المراحل بالترتيب (عنوان + وصف + رابط مصدر لكل مرحلة)`.
3. سنقوم بنسخ `pages/career-path.html` إلى ملف جديد لكل مسار (مثلاً `pages/path-frontend.html`) وملء البيانات — الهيكل والتصميم جاهزان.

**لا حاجة لإعادة بناء المشروع** — كل المواضع والفلاتر والبحث سيعمل فور تركيب البيانات.

## 7. القرارات التقنية

- **بدون أطر عمل** تنفيذًا للطلب — كود قابل للصيانة ومفصول (HTML/CSS/JS).
- **CSS Variables** للهوية: تغيير ` --color-primary / --color-accent` في `variables.css` يغيّر الموقع بالكامل، بما في ذلك الوضع الداكن.
- **Mobile-First + Sticky Navbar + Backdrop Blur** لمظهر عصري وخفيف.
- **RTL كامل** مع `dir="rtl"` وخطوط عربية، وكل المسافات تستخدم `margin-inline` بدلاً من `left/right` حيث أمكن.
- **Empty States بدل بيانات وهمية** التزامًا بالتعليمات الإلزامية — كل قسم يوضح بوضوح أنه بانتظار المحتوى.
- **بحث واجهة فقط** — تم تجهيزه بصريًا وتفاعليًا (Overlay، اختصارات، حالات فارغة) دون افتراض قاعدة بيانات.
- **نموذج مسار واحد قابل للتكرار** (`career-path.html`) بدل إنشاء صفحات فارغة متعددة — أكثر قابلية للصيانة.
- **لا خدمات خارجية** — الخطوط من Google Fonts فقط (يمكن استبدالها بخطوط محلية لاحقًا بسهولة)، لا APIs مدفوعة.
