📜 قوانين السيرفر

1. الاحترام المتبادل

يجب احترام جميع الأعضاء. يمنع التنمر أو الإهانة أو التمييز أو المضايقات.

2. المحتوى المناسب

يمنع نشر أي محتوى غير لائق أو مسيء أو مخالف للآداب العامة.

3. منع السبام

يمنع إغراق القنوات بالرسائل أو المنشنات أو الإيموجي أو الروابط بشكل مزعج.

4. الالتزام بموضوع القنوات

استخدم كل قناة للغرض المخصص لها وحافظ على تنظيم المحتوى.

5. منع الإعلانات غير المصرح بها

يمنع الترويج لسيرفرات أو حسابات أو منتجات دون موافقة الإدارة.

6. حماية الخصوصية

لا تشارك معلوماتك الشخصية أو معلومات الآخرين داخل السيرفر.

7. الالتزام بتعليمات الإدارة

يجب احترام قرارات الإدارة والمشرفين والتعاون معهم.

8. استخدام غرف الدراسة بشكل صحيح

غرف الدراسة مخصصة للتعلم والمناقشات المفيدة والتعاون بين الأعضاء.

9. مشاركة المعلومات الموثوقة فقط

عند مشاركة المعلومات أو المصادر أو الفرص أو الأدوات أو النصائح، يجب أن تكون من مصادر موثوقة أو مبنية على تجربة شخصية حقيقية. يمنع نشر معلومات مضللة أو غير مؤكدة أو تقديمها على أنها حقائق دون التحقق منها.

مخالفة القوانين قد تؤدي إلى إنذار أو كتم أو إيقاف مؤقت أو طرد أو حظر دائم حسب نوع المخالفة.
